# FilmTrackerBot

Telegram-бот, который помогает вести список фильмов: добавлять их в «Хочу посмотреть», отмечать просмотренные и ставить оценки.

![Python](https://img.shields.io/badge/python-3.11+-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## Возможности

- Добавление фильмов по названию
- Списки «Хочу посмотреть» и «Просмотрено»
- Оценка фильма от 1 до 10
- Случайная рекомендация из вашего списка

## Требования

- Python 3.11 или новее
- Токен бота от [@BotFather](https://t.me/BotFather)
- SQLite (входит в стандартную библиотеку Python)

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/username/film-tracker-bot.git
   cd film-tracker-bot
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate   # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` и укажите токен:
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

## Быстрый старт

```bash
python main.py
```

Откройте бота в Telegram и отправьте `/start`. Если всё получилось, бот ответит приветствием.

## Команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `/start` | Приветствие и краткая справка | `/start` |
| `/add <название>` | Добавить фильм в «Хочу посмотреть» | `/add Интерстеллар` |
| `/watched <название>` | Отметить фильм как просмотренный | `/watched Интерстеллар` |
| `/rate <название> <1-10>` | Поставить оценку | `/rate Интерстеллар 9` |
| `/list` | Показать все списки | `/list` |
| `/random` | Случайный фильм из «Хочу посмотреть» | `/random` |

## Настройки

| Переменная | Обязательная | По умолчанию | Описание |
|------------|--------------|--------------|----------|
| `BOT_TOKEN` | Да | — | Токен бота |
| `DB_PATH` | Нет | `films.db` | Путь к файлу базы данных |
| `LOG_LEVEL` | Нет | `INFO` | Уровень логирования |

## Частые проблемы

**Бот не отвечает.** Проверьте, что `BOT_TOKEN` указан верно и скрипт запущен без ошибок.

**Ошибка `ModuleNotFoundError`.** Активируйте виртуальное окружение и повторите `pip install -r requirements.txt`.

**Бот не находит фильм.** Названия ищутся без учёта регистра, но писать их нужно полностью.
