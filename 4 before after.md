# Пример рерайта: до и после

## До

> Для того чтобы осуществить установку бота необходимо предварительно произвести настройку окружения, после чего выполнить клонирование репозитория и установку зависимостей, и затем уже запускать приложение, при этом не забыв про токен, который нужно получить у BotFather, иначе ничего работать не будет.

**Что не так:**
- одно длинное предложение вместо шагов;
- канцелярит («осуществить установку», «произвести настройку»);
- непонятно, что именно делать и в каком порядке;
- важное условие (токен) спрятано в конце.

## После

### Установка

**Перед началом** получите токен у [@BotFather](https://t.me/BotFather).

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/username/film-tracker-bot.git
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте файл `.env` и добавьте токен:
   ```
   BOT_TOKEN=ваш_токен
   ```
4. Запустите бота:
   ```bash
   python main.py
   ```

**Что изменилось:**
- предложение разбито на нумерованные шаги;
- каждый шаг начинается с глагола и содержит одно действие;
- условие про токен вынесено в начало;
- команды оформлены как код, их можно скопировать.

## Принципы, которые я применил

1. Один шаг — одно действие.
2. Предварительные условия идут первыми.
3. Простые слова вместо канцелярита.
4. Команды и названия файлов выделены кодом.
